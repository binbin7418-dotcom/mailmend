How duplicates are caught — two ways

  • By Message-ID, normalized — a copy whose ID differs only in letter case or spacing is still caught
  • By content key (sender + subject + date + body) for mail with no Message-ID — a re-exported copy hiding behind a different Received header is caught too

What it repairs — and never does

It rejoins messages split by a fake envelope line in the body (escaping the line, losing nothing). It never modifies your original file, never fabricates a Message-ID, and never guesses: kept messages are byte-preserved, attachments untouched.
